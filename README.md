# 石組みを適用した現地マップ

石組み構造物を紹介する現場の位置図・一覧と、現地写真から作った3Dモデル（オッカバケ川 朔北橋、コルゲート管出口）をまとめたWebページです。

- `index.html` … 地図ページ（現場カード・紹介ボード・石組みのここがすごい！）
- `sakuhoku/` … オッカバケ川（朔北橋）の3Dモデル
- `culvert/` … コルゲート管出口の3Dモデル（改善前・改善後）
- `boards/` … 紹介ボード画像、`cards/` … 現場カード写真、`merits/` … 「ここがすごい！」の写真

周辺の地形と航空写真は、地理院タイル（標高タイル・シームレス空中写真）を加工して作成（出典：国土地理院）。海岸線: Natural Earth。

AIの学習への利用はお断りします（`robots.txt` と `noai` 指定）。

## 公開のしかた
リポジトリを Public にしたあと、Settings → Pages → Branch を `main` / `/ (root)` にすると公開されます。
